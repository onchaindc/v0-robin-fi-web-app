# World Is Flat Hackathon — RobinFi

## Concept
RobinFi: One-click diversified ownership of Stock Tokens on Robinhood Chain, paired with a real voice via $WIF voting on World Is Fair.

Ownership is not only holding an asset — it is having a voice in what gets built next.

## Why this fits
- Built on Robinhood Chain (chain ID 4663)
- Leverages Stock Tokens (TSLA, AAPL, NVDA, etc.)
- Integrates the $WIF token and World Is Fair voting narrative
- Aligns with the thesis: talent is everywhere, opportunity should be too

## How to run
```bash
npm install
npm run dev
```

Connect a wallet on Robinhood Chain mainnet.

## $WIF
Contract: `0x5173b8ea6923c2d40267890d45c46a3480954773`

Voting: send 1 $WIF to an option’s deposit address on https://worldisflat.fun/fair — tokens are burned.
